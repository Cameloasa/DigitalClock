# 🌺 Midnight Bloom — Digital Clock

**Midnight Bloom** is an artistic digital clock built with HTML, CSS, JavaScript, and Bootstrap 5. Inspired by botanical details and a midnight color palette, the project combines a minimalist interface with practical timekeeping features.

## ✨ Features

- **Live digital clock** — displays the current local time and updates every second.
- **12-hour and 24-hour formats** — switch between time formats with a button.
- **Current date** — displays the weekday, month, and day.
- **Light and dark themes** — switch between two carefully designed color palettes.
- **Responsive design** — adapts to desktop, tablet, and mobile screens.
- **Accessible controls** — includes descriptive button labels, keyboard focus indicators, and accessible state information.

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript (ES6+)
- Bootstrap 5.3.3
- Google Fonts

## 🚀 Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/Cameloasa/DigitalClock.git
   ```

2. Open the project folder:

   ```bash
   cd DigitalClock
   ```

3. Open `index.html` in your browser.

No build tools or package installation are required.

## 🎨 Design Concept

Midnight Bloom uses a rich plum background, warm ivory typography, coral highlights, and subtle botanical-inspired decorations created with CSS.

The project explores how a simple JavaScript application can become a more expressive and accessible user interface without requiring a JavaScript framework.

## 📚 Learning Goals

- Working with JavaScript's `Date` and `Intl.DateTimeFormat` APIs.
- Updating the DOM dynamically.
- Handling button interactions with event listeners.
- Switching themes using CSS classes and custom properties.
- Building responsive layouts with CSS and Bootstrap.
- Improving accessibility through semantic HTML and ARIA attributes.
